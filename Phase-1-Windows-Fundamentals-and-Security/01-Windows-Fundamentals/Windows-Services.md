# Windows Services

**Module:** 1 — Windows operating system fundamentals

The Task Manager Services page showed these five services running:

| Service name | Status | Purpose |
|---|---|---|
| Appinfo | Running | Helps Windows launch some applications with elevated permissions when needed. |
| AppXSvc | Running | Supports deployment and management of Microsoft Store apps. |
| AudioEndpointBuilder | Running | Sets up audio devices and audio endpoints for Windows. |
| Audiosrv | Running | Manages Windows audio for applications. |
| BITS | Running | Transfers files in the background; Windows Update and other applications can use it. |

Other services in the screenshot were stopped. That can be normal: some services start only when needed. No service settings were changed as part of this exercise.
