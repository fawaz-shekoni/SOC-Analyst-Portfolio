# Module 7: Basic Windows troubleshooting

These are three practice investigations on the main Windows PC. The evidence records what was visible during each check; it does not establish that the PC currently has a persistent fault.

## Reports

- [Slow after sign-in](Slow-After-SignIn.md)
- [Application crashes](Application-Crash.md)
- [Network connectivity](Network-Connectivity.md)

Screenshots are in [evidence](evidence/README.md). Personal identifiers and the Wi-Fi network name were removed from the published images.

## Scope

No settings, startup entries, drivers, or applications were changed during these investigations. The slow-PC evidence is a single Task Manager snapshot, crash evidence comes from historical Event Viewer records, and the network check confirms that one page loaded at the time of capture only.
