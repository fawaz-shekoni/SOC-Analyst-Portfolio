A hands-on learning portfolio documenting my progress toward becoming a SOC Analyst. Each module includes concepts, practical observations, and evidence gathered during exercises.

## Module 1: Windows operating system fundamentals

- [Windows architecture](01-Windows-Fundamentals/Windows-Architecture.md)
- [Running processes](01-Windows-Fundamentals/Running-Processes.md)
- [Windows services](01-Windows-Fundamentals/Windows-Services.md)
